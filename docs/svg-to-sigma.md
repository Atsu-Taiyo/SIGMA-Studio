# SVG画像を図形へ変換する

SVG画像を右クリックし「図形に変換」を選ぶ。本文モードからも直接開ける。
複数の部品はグループになり、「グループ解除」で各部品を編集できる。
変換は通常の文書履歴を通り、Undo 1回で元のSVG画像へ戻る。

直線、折れ線、四角形、円・楕円、多角形、直線だけのpath、1本の2次ベジェ（`Q`）だけのpathをSigmaDocの図形へ変換する。
2次ベジェはcurve種の線（3点）になる。
底辺が水平な三角形は既存のtriangle図形、それ以外の三角形・多角形は閉じたline図形になる。
塗りつぶし、線と塗りの色・透明度、viewBox、継承スタイル、座標変換を取り込む。
線の太さは既存の5段階（極細0.75px・細1.25px・中2px・太3px・極太5px）のうち最も近いもの、stroke-dasharrayは実線・破線・点線へ合わせる。
極細は保存値 `xs` を使うため、未対応の旧アプリでは図形が除外されたり共有教材を開けなくなったりする。
リリース時は共有教材の参加者へ更新を案内する。変換処理も細い線に `xs` を使用する。
四角形・三角形は、編集画面が図形の線を箱の1px内側へ描くので、箱を元の輪郭より上下左右に1pxずつ大きくして、同じ大きさ・位置に見えるようにする。
円・楕円は箱の半幅・半高をそのまま半径に使うため、この1px補正を加えない。
表示倍率・viewBox・要素のtransformを反映した直径（楕円は幅または高さ）が、図形リサイズの最小サイズ1px未満なら、
拡大せずその部品をSVG画像として残す。ほかの変換可能な部品は図形になる。小さな円だけのSVGは元画像を保持する。

文字はoverlay textへ変換し、色・フォント・文字サイズ・太字・斜体・下線と開始/中央/末尾揃えを取り込む。
斜体の単独変数、添字付きの記号、短い記号の式は既存のmathInlineへ変換する。
「張力 T」のような日本語と変数の混在は同じテキスト図形の中の通常文字と数式になる。
単独のVや数字、英単語など曖昧なラベルは通常文字を優先する。OCRやAI推定は行わない。
数式のTeXはSVGの文字から安全な記号だけを組み立てる。SVG内の文字をTeXとして直接実行しない。
実アプリは本文と共通の描画器・数式環境でサイズとベースラインを計測し、元の位置へ配置する。
複雑なtspanの座標指定、変形、輪郭線のある文字、文字がpathになっているSVGは自動で文字へ復元しない。

線・折れ線・曲線の`marker-start` / `marker-end`は、線自身の矢じり（`arrowheadStart` / `arrowheadEnd`）へ変換する。
塗りの三角形は`triangle`、開いたV字は開き角の近い`thinArrow` / `arrow` / `openArrow`、塗りの円は`dot`になり、
線幅に対するマーカーの大きさで標準かSmallかを選ぶ。矢じりの先端はマーカーの先端が来る位置へ合わせる。
編集画面の矢じりは線の外を向くので、その端で外を向いて描かれるマーカーだけを変換する。
`orient="auto-start-reverse"`、`orient="auto"`（開始側は−x向きに描いたマーカー。両端矢印を2つのマーカーで書く形）、
線の向きに沿った数値の`orient`（省略時の0を含む）を読み、マーカーの色が線の色と同じものだけが対象になる。
`orient="auto"`のまま開始側に付けた+x向きのマーカーのように線の内側を向く矢じりは、SVG画像として残す。
それ以外のマーカーや`marker-mid`、複数のsubpathを持つpathのマーカーはSVG画像として残す。

トリミングされた画像、画像の枠と縦横比が違う画像は、キャンバスに表示されている範囲だけを変換する。
表示範囲に収まる部品は図形になり、範囲の外にある部品は捨てる。境界をまたぐ部品は図形にできないので、
表示範囲へ切り取ったSVG画像として元の重なり順に残す。トリミングで隠れていた部分は変換後に戻せない。

2次ベジェ以外の曲線（3次ベジェ・円弧・`T`でつないだ曲線）、クリップ、グラデーション、グループの透明度など、既存の図形で
表せない部分はSVG画像として元の重なり順に残す。実アプリでは各断片の表示範囲を計測し、
周囲の図形を選ぶ邪魔にならないよう画像をトリミングする。
トリミング済みの画像や縦横比の異なる枠でも、キャンバスと同じ表示範囲・座標で変換する。
境界をまたぐ部品は、その表示範囲をSVG自体のviewportへ焼き込んで残す。細い断片でも画像トリミングの
最小比率に左右されず、隠れていた部分は現れない。範囲外の部品は実アプリの計測で除外する。
変換可能な部品がない場合や読み込みに失敗した場合は元の画像を保持して理由を表示する。
外部参照、スクリプト、CSSスタイルシートなどは扱わない。
共有（クラウド同期）文書のSVGは `sigma-doc-storage://` の参照で持たれ、rendererからは`fetch`できない。
変換は`DocumentSession.readAssetSource`でセッションの実体（`data:`）を読んでから行う。

所有箇所:

- `features/drawing/svg-to-shapes.ts`: DOM非依存の座標・基本図形の変換。
- `features/drawing/svg-path.ts`: pathの直線・単一の2次ベジェのsubpathへの分解。
- `features/drawing/svg-markers.ts`: マーカーの絵を矢じりへ分類し、大きさと先端の位置を求める。
- `lib/svg-image-source.ts`: 静的XMLの検証、属性の解釈、貼り付けるSVGの寸法。
- `lib/svg-to-sigma.ts`: 継承、マーカー定義の収集、トリミング範囲の算出、SVG断片の保持、画像の置換とアセット整理。
- `lib/svg-text-to-overlay.ts`: テキストの書式、数式判定、正本のInlineNodeとテキスト座標への変換。
- `overlay-canvas/svg-fragment-bounds.ts`: 検証済みの静的ノードを使った一時SVGの計測と撤去。
- `overlay-canvas/svg-text-measurement.tsx`: 共通の本文描画器で文字と数式の寸法・ベースラインを計測し、一時DOMを撤去。
- `overlay-canvas/use-svg-conversion.ts`: 編集権限、共有アセットの実体の読み出し（`readAssetSource`）、文書切替時の破棄、履歴への確定。
- `PageCanvasEditor`と`OverlaySelectPointRequest`: 本文モードの右クリックからキャンバスのメニューへの引き継ぎ。

保存スキーマは追加しない。既存のgeo、line、text（text/mathInline）、group、imageとアセットを正本のSigmaDoc JSONへ保存する。
