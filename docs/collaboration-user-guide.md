# 教材を共同編集する

普段の教材は端末だけに保存されます。無料プランでは同時に1教材を共有でき、所有者以外に閲覧者を含め1人まで招待できます。Proでは共有教材数が無制限になり、教材ごとに15人まで招待できます。招待された参加者は無料で利用できます。詳しくは[プランの説明](sharing-plans.md)を参照してください。共同編集する教材で「共有」を開き、「Googleでログイン」でブラウザの認証を完了し、アプリに戻って「共有を開始」を選びます。画像の準備と同期が終わったら、招待コードを作成できます。

相手は自分のアプリで「共有」からログインし、招待コードを貼り付けて「招待に参加」を選びます。参加した教材は教材一覧から開けます。招待コードは7日間有効で、発行者が無効にできます。

「編集者」は本文・図・表・コメントの編集とAI提案の承認ができます。フォルダ・ワークスペースの編集者は、その共有範囲内で教材やフォルダを作成できます。「閲覧者」は内容を見ることができますが、編集や教材・フォルダの作成はできません。「管理者」は編集と参加者の管理ができます。所有者は管理者を含む参加者の権限を変更できます。権限はGoogleアカウントごとに適用され、親から継承した権限と直接付与した権限のうち強い方が有効です。解除済みの人が以前端末へ保存した内容を、遠隔で消す機能はありません。

フォルダを共有すると、後から作った配下のフォルダや教材にも権限が引き継がれます。所有者の画面では元のワークスペース内に残り、受け取った側では「共有アイテム」に表示されます。ワークスペース全体を受け取った場合は、左サイドバーから開けます。

複数の教材を並べて表示するには、開いているタブを教材表示領域の上下左右の端へドラッグします。最大3つの表示領域に分割でき、境界をドラッグして幅や高さを調整できます。ほかの領域も編集画面と同じ倍率・見た目のまま表示され、押した位置にキャレットが置かれてその教材が編集対象になります。分割状態は再起動後も復元されます。

画面上部の雲アイコンに保存状態が表示されます。「端末保存済み・未同期」はまだ他の人に届いていません。「クラウド保存済み」はサーバーでの保存まで確認できた状態です。通信が切れても端末で編集を続けられます。再接続時に権限を確認してから未送信の編集を送ります。

AIとの会話や承認前の案は、自分の端末だけに保存されます。共有教材ではAIの処理中も手で編集できます。承認時に参照元や変更対象が変わっていた場合、その案は適用されません。最新の内容を読ませて案を作り直してください。共有教材の承認はオンライン時に行います。元に戻す操作は自分の変更を対象にします。

AIの「適用を取り消す」も、指定した案の変更だけを対象にします。取り消し履歴は起動中に限られ、再起動後は最新の内容から編集し直します。

画像は共有用に保存され、他の人のアプリにも取得されます。一度取得した画像はオフラインでも利用できます。未取得の画像がある状態でのPDF出力は失敗として通知されます。

共有画面の「詳細」から、同期状態の確認、バックアップ、端末だけで使うローカルコピーの保存ができます。共有の停止は全員の同期を止め、退出は自分の参加を終了します。サーバーから削除するとその教材へアクセスできなくなります。これらは端末の教材を自動で複製・削除する操作ではありません。

所有者がバックアップから復元すると、全員の共有教材がその版になります。復元前にオフラインで入力した内容は自動送信されません。必要なら先にローカルコピーを保存し、「復元後の教材を開く」を選びます。

保存エラー時は、アプリを閉じる前に保存状態を確認してください。権限エラーは所有者へ確認します。端末の保存が壊れた場合は元データを消さず、開発者へ調査を依頼してください。未設定の表示は共同編集用の接続先が設定されていない状態で、ローカル教材の編集は継続できます。
