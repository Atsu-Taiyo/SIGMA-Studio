# 二次関数グラフ設定UIの統一: before / after

PR 用の画面写真です。どれも同じ手順で撮りました。Playwright と desktop runtime mock で、このチェックアウトの Next dev サーバーに接続しています。

1. 「挿入 → グラフ」でグラフを挿入する
2. 右クリックして「グラフの設定…」を開く
3. 「関数を追加」を押し、式に `x^2-2x-1` を入れる

ビューポートは 1440×1000 です。

## before（main / c80ad271）

| ファイル | 内容 |
|---|---|
| `before-01-panel-initial.png` | 開いた直後の画面。関数カードに出ているのは式だけです。線の種類・色・太さは見えず、「表示範囲」と「軸名」は畳まれた別の節になっています。 |
| `before-02-line-style-popover.png` | カードの `⋯` に hover した状態。線の色・線種・太さとグラフ上の式の表示はこのポップオーバーの中にしかありません。 |
| `before-03-function-type-and-range-sections.png` | 「詳細」「表示範囲」「軸名」を開いた状態。関数の種類（向き）と定義域はカードの「詳細」、値域（軸の表示範囲）・目盛・軸は「表示範囲」、軸名はさらに別の節にあり、見出しの体裁もそれぞれ違います。定義域の入力欄は狭く、値が切れています。 |

## after（このブランチ）

| ファイル | 内容 |
|---|---|
| `after-01-unified-panel.png` | 開いた直後の画面。関数カードの「式・種類・線・定義域・ラベル」と「座標軸と範囲」の各行を、同じ「ラベル \| 操作」の行で並べています。値域（x軸・y軸の範囲）は関数カードのすぐ下に、開いた状態で出ます。 |
| `after-02-axes-and-range-section.png` | 「座標軸と範囲」の節を末尾までスクロールした画面。範囲（x軸・y軸・描画範囲）、目盛（間隔・文字サイズ）、軸（表示・先端・軸名）が1つの節にまとまり、ラベル列の位置は関数カードと揃っています。 |
| `after-03-style-and-domain-follow.png` | カードの「線」の行で線種を「破線」、色を赤にし、定義域を −1 ≦ x ≦ 3 にした状態。hover メニューを開かずに操作でき、グラフの描画もすぐ変わります。 |
| `after-04-range-and-grid-follow.png` | 続けて、同じパネルで x軸を −3〜5、y軸を −3〜4 にし、グリッドを有効にした状態。グラフの範囲とグリッドがそのまま描画に反映されています。 |
