# 共同編集のプラン

教材のローカル作成・編集・保存は無料です。招待された参加者に Pro 契約は必要ありません。

| | 無料 | Pro |
| --- | --- | --- |
| 料金 | $0 | 所有者1人につき月額$9 USD |
| 同時に共有できる教材 | 1件 | 無制限 |
| 教材ごとの参加者 | 所有者以外は閲覧者を含め1人 | 所有者以外は閲覧者を含め15人 |
| 共有対象 | 教材単体 | 教材・フォルダ・ワークスペース |
| 権限 | 編集者・閲覧者 | 管理者・編集者・閲覧者 |

管理者は参加者を追加できます。人数は教材ごとに数え、複数の経路で参加している同じ人は1人です。画像や履歴にプラン別上限は設けません。

無料枠は編集者と閲覧者を合わせて1人です。編集者1人に加えて、別の閲覧者1人を招待することはできません。

無料プランで Pro の範囲に当たる操作（フォルダ・ワークスペースの共有、2件目の教材の共有、2人目の招待、管理者の設定）をすると、その場でプラン画面が開きます。プラン画面の見出しには、止めた操作と理由を書きます。操作前に「Proの機能です」という案内を並べることはしません。招待された側が参加人数の上限に当たった場合は、招待者のプランの問題なのでプラン画面は出さず、招待した人に確認するよう伝えます。

Pro は初回7日間無料です。本人が開始を選び、カードを登録します。アカウントにつき1回利用でき、7日後に月額$9の自動更新へ移行します。契約の管理はアカウントメニューから行えます。購入機能は運営サーバーの決済設定が完了した環境で利用できます。

解約後は支払済み期間の終了まで Pro が有効です。支払い失敗時は7日間の猶予と警告が表示されます。失効後は Pro 加入前に無料共有していた教材だけを残し、参加者は管理者、編集者、閲覧者の順に1人を選びます。同じ権限の候補からは無作為に一度だけ選びます。残った管理者の権限は編集者になります。元の無料共有がない場合や停止・削除済みの場合は、自動で別の教材を無料枠へ移しません。

ロックされた共有データは削除されません。所有者はアカウントメニューから最新の本文と画像をローカルコピーとして保存できます。再契約すると保持された共有を再開できます。無料共有を停止・削除した後は別の教材を共有できます。
