# 普段の編集を次のAI提案に反映する

個人教材を手で編集して保存すると、変更前後の実例を自動で覚えます。スキルの作成・選択・評価ボタンの操作は不要です。同じワークスペースで次にAIへ依頼すると、最近の実例がCodex・Claude・Antigravityへ渡ります。続きの会話でも毎回読み直します。

対象は本文、問題の導入文・問題文・コメント・解答、見出し、リスト、囲み記事内の文章です。語尾・文体に加え、TeX、改行、文字の強調、段落の揃え方、コメントに付随する問題文を保持します。AIには実際の差分を参考にさせ、単発の変更や数学的な訂正を恒久的な文体規則へ一般化しないよう伝えます。

AI提案の承認・自動承認、バックアップの復元、変更時刻だけの更新、失敗した保存、共有教材の同期は学習の根拠にしません。AI案を採用した後で手直しした箇所は、その手直しを実例にします。教材の取り込みだけで本人の文体とは決めません。問題文や数値を他の教材へ複製する指示には使いません。

実例はユーザーデータ内の `data/ai-authoring-style/examples.json` に保存します。教材本体とユーザーが書いたスキルは変更しません。最大160件、1箇所の連続した自動保存は1件にまとめ、元へ戻した変更は取り除きます。次の依頼には対象教材を優先して最大8件、実例のJSONは最大9,000字を渡します。削除・移動した教材は現在のライブラリ所属を確認し、対象外のワークスペースへ持ち出しません。

これは実例を使った提案の個人化で、モデルの重みの再学習ではありません。導入前の全教材の一括分析、図形・吹き出しやレビュー用コメントスレッド、提案の却下理由からの学習は含みません。実例の受け渡しと生成品質の向上は別に評価します。
