# UI components

このディレクトリは、Sigma Studio のデザインルールを実装へ固定するための共通UI層です。見た目と基本操作だけを統一し、SigmaDoc、AI実行、グラフ編集などの業務状態は持ちません。

## Component intent

| Component | 意図 | 持たない責務 |
| --- | --- | --- |
| `Stack` | 縦方向の配置と兄弟要素間の余白をトークンで統一する | 色、境界線、業務状態 |
| `Inline` | 横方向の整列、折り返し、余白を統一する | ツールバー固有の操作 |
| `Inset` | カードやパネルの内側余白を外側レイアウトから分離する | カードの色、影、選択状態 |
| `Center` | 集中画面の最大幅と画面端ガターを統一する | 内部の縦横配置 |
| `Grid` | 同種項目の列数と間隔を統一する | 各項目の意味や装飾 |
| `Button` | primary / secondary / ghost / danger の操作階層と、文字を含む操作面の共通角丸を統一する | 確認ダイアログ、保存処理 |
| `IconButton` | AIチャットの送信ボタンを基準とした真円の操作面、ヒット領域、ツールチップ、アクセシブル名を保証する | アイコンの意味や実行処理 |
| `ModalFrame` | body portal、背景隔離、面、幅、フォーカス循環、Escape、復帰、積層を統一する | 見出しや本文の情報設計 |
| `ModalHeader` | 見出し階層と右上の閉じる操作を統一する | 保存・キャンセルなどの業務判断 |
| `ModalBody` | モーダル本文のスクロールと内側余白を統一する | セクション間のレイアウト |
| `Select` | 選択肢の一覧をOSではなくアプリ内のポップオーバーで見せ、キーボード操作と現在値の表示を統一する | 選択肢の中身、値の意味、保存処理 |
| `ChoiceGroup` | 少数の排他選択を、形が意味を持つアイコンカードとして一覧のまま見せ、radiogroup のロールとroving tabindexを保証する | 選択肢の意味、アイコンの選定、保存処理 |
| `Disclosure` | 補助設定を必要な時だけ開示する | 主要操作や必須状態の隠蔽 |
| `Tooltip` | 曖昧なアイコン操作へ短い結果説明と現在のキー割り当てを補う | 対象操作の選定、ショートカット設定の解決 |
| `Shimmer` | 待ち時間を最終レイアウトに近い形で示す | 保存・同期などの短い状態表示 |
| `SettingsSection` | 関連設定を一つの見出し階層と縦リズムへまとめる | ダイアログ外枠、値の保存 |
| `SettingsRow` | 設定名・補足と操作の対応を保ち、狭幅では積み替える | 入力値の検証、永続化 |
| `SettingsField` | ラベル、補助情報、入力を一つのフォーム項目として結ぶ | 入力部品の状態、検証規則 |
| `SettingsStatus` | 保存結果や局所エラーを該当箇所で通知する | Toastの寿命、文言決定 |
| `Switch` | 二値設定を色以外でも判別できる共通操作にする | 楽観更新、保存、ロールバック |
| `Tabs` | 排他的な設定ビューのARIA関連付けとキー移動を統一する | 各パネルのデータ取得、業務状態 |
| `AiProposalDecisionButton` | AI提案の破棄と適用を同じ記号・大きさ・操作階層へ揃える | 提案内容、適用処理、確認フロー |
| `AiProposalActions` | 破棄・続けて修正・適用の並びと待機状態を全提案カードで統一する | 提案状態の所有、SigmaDocへの書き込み |
| `AiAppliedChangeCard` | 適用済みAI提案の実差分と安全な取消導線を、コンパクトな一つの結果面へ揃える | プロバイダー識別、差分の生成・描画、競合・revision判定、巻き戻し処理 |

## Usage boundaries

- 余白には `--space-*` または layout primitive の token props を使う。
- layout primitive に背景、枠、影、業務ロジックを追加しない。
- モーダルを新設する場合は独自backdropを作らず、`ModalFrame`を使う。
- 選択肢から値を選ぶUIはネイティブの `<select>` を使わず `Select` を使う。選択肢が少数で、かつ選ぶ対象の**形そのものが情報**である場合 (グラフの種類など) は `ChoiceGroup` を使い、一覧を閉じない。OSのカラーパネル (`input[type="color"]`) や日付ピッカーも同様に使わない。ESLintの `no-restricted-syntax` で機械的に防いでいる。
- モーダルのz-indexを画面側で上書きせず、通常・入れ子の積層は `layer` と共通トークンへ委ねる。
- アイコンだけの操作は `IconButton` を使い、`label` を必ず渡す。
- `Tooltip` は記号だけでは結果が曖昧な操作にだけ使う。閉じるなど慣例的に明確な操作へ一律追加しない。
- キー割り当てを表示する場合は固定文字列にせず、現在有効なショートカットを呼び出し側で解決して渡す。未割り当てならキー欄を省略する。
- `IconButton` は幅と高さを揃え、既定の `--radius-round` で真円にする。画面固有CSSで角丸へ戻さない。
- 文字を含む `Button` は `--radius-control` を使い、アイコンだけの操作を表すために無理に真円へしない。
- 削除操作は `danger` を使い、即時実行が危険な場合は確認またはUndoを別途用意する。
- 詳細開示に `Disclosure` を使う場合も、主要操作と重要な状態は閉じた領域へ入れない。
