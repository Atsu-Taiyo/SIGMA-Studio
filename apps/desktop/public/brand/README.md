# Google sign-in mark

`google-g.png` is the unmodified Google sign-in mark from https://developers.google.com/static/identity/images/g-logo.png, downloaded 2026-09-22 for the Google sign-in button.

Use it only according to https://developers.google.com/identity/branding-guidelines. Google owns the Google trademarks. The asset is bundled so authentication does not require a third-party image request.
