# 校正・言い換え・表記ゆれを直す

校正は「必要な箇所だけを、元の書式ごと保って」直す作業。段落や問題を丸ごと書き直さない。意味と数学的な内容を変えない。

## 範囲を決める

- 「選択部分だけ」「この段落」の指示は、`get_edit_context`（`runId` を渡す）の `context.selection` にある全参照・全ブロックが対象。他の場所は触らない。
- 教材全体の校正は、`get_document_outline` でブロックを列挙し、`get_blocks`（一度に最大10件）で本文を読みながら、1まとまりずつ進める。全文が要るときだけ `read_local_document` の detail を full にする。
- 特定の語を探すときは、全文を読まず `search_document`（本文・TeX・表のセル・図形内の文字まで検索できる）。

## 直し方

1. 直す箇所を洗い出し、種類で分ける: 誤字脱字、変換ミス、表記ゆれ（漢字・ひらがな・送り仮名、「ください／下さい」、半角全角、句読点）、文体（です・ます／だ・である）、用語・記号の不統一、単位の書き方、言い回し。
2. 教材の中で先に決まっている表記に揃える。決まっていない揺れは、多いほうか、教科書的な表記に統一し、基準を最終報告に書く。
3. **`edit_text` の patch（`replace_text`）で差分だけ送る。** 1回に最大20件まで。
   - 位置は `{"type":"range","blockId","from","to","quote"}`（`quote` は現在の本文と一致する必要がある）、または完全一致の `{"type":"text","blockId","text","occurrence"}`。
   - 元のフォント・ptサイズ・太字・色・囲みと、範囲外の内容は保たれる。
   - 同じ語を教材全体で揃えるときは、`search_document` で全件のブロックを出し、`occurrence` を数えて1件ずつ指定する。
4. 言い換えで文の構造ごと組み替えるときも、まず patch で足りるか考える。段落内のrun構造を組み替える必要があるときだけ `edit.action` を update にして、既存の数式（math）は**同じ `id` のまま** runs に残す。
5. 図形・表のセル・吹き出しの中の文字は本文ではない。`update_shape`（text 図形）や `update_table` の `cellPatches` で直す。

## 守ること

- **数式（math）は原則触らない。** 明らかなTeXの誤植（括弧の不一致、未対応コマンド）だけを直す。数式の中身に数学的な誤りがありそうなときは、勝手に直さず指摘として報告する（ユーザーが訂正を頼んだときだけ直す）。
- 問題文の条件・数値・固有名詞・引用は変えない。言い換えは意味が同じである範囲に限る。
- 教材の言語のまま直す。日本語の教材を英語にしない。
- 問題番号や「解答」の見出しは自動で付くので、本文へ足さない。
- 判断が割れる直しは、勝手に確定せず、候補と理由を示して聞く。
- 頼まれていない箇所の「ついでの改善」をしない。気づいたことは、直さずに報告に添える。

## 確認と報告

書き込み後の `verification.validation` にエラーが無いこと、`verification.preview` で行の折り返しやはみ出しが増えていないことを見る。最後に、直した箇所を「変更前 → 変更後（理由）」の短い一覧にして報告する。直していない指摘と、統一の基準も分けて書く。
