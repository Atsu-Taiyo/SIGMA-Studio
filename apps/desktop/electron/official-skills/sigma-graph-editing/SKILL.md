# グラフを挿入・更新する

座標系で値や関係を読ませる図だけをGraph2Dとして作る。

## ツールの選択

- 新しい関数グラフ、座標平面、数直線、方程式・不等式の領域図には `insert_graph` を使う。
- 既存グラフは作り直さず、`update_graph` で必要な項目だけを更新し、位置・サイズ・既存スタイルを保つ。
- 三角形、円、矢印、補助線、模式図、独立した注記など、座標系そのものを読ませない図には `insert_shape` または `update_shape` を使う。

## Graph2Dの組み立て

1. 描画範囲を `viewBox` の `xMin`、`xMax`、`yMin`、`yMax` で定める。曲線、点、領域が余白付きで収まる最小限の範囲にする。
2. `axes` で軸、グリッド、目盛り、軸ラベルを指定する。通常は両軸を表示し、グリッドと目盛りは教材上必要な場合だけ有効にする。目盛り間隔は `xTickStep` / `yTickStep`、π表示はtick modeで制御する。
3. 関数は `curves` に入れる。`expr` は評価式、`label` は表示式として分け、`mode` を `yOfX`、`xOfY`、`parametric`、`implicit` から選ぶ。必要な区間だけ描く場合は `domain` を指定する。
4. 特別な座標は `points`、説明は `annotations`、閉領域は `fills` に入れる。境界上ではなく領域内部にfillの内部点を置く。
5. 軸名、原点、点ラベル、注釈、曲線式ラベルはグラフ所有のtext labelとして扱う。独立図形へ分解せず、自動配置・自動採寸を優先する。重なりを避けたい点だけ `labelPlacement` を指定する。
6. 教材の基本配色は白黒にする。主曲線は黒の実線、補助曲線や第2曲線はグレーまたは破線・点線で区別する。色指定がある場合だけ色を使う。

## 確認と修正

`insert_graph` / `update_graph` の返すverification previewを実際に確認する。必要なら `render_block_context` で周辺の紙面も確認する。

- 曲線の形、定義域、交点、極値、塗り領域が数学的に正しいか。
- x軸・y軸・原点・目盛りが意図どおりか。
- 軸ラベル、点ラベル、注釈、曲線式が曲線や互いに重なっていないか。
- グラフ全体が小さすぎないか、紙面やshape boundsからはみ出していないか。
- 不要なグリッド、目盛り、装飾、色が追加されていないか。

問題があれば `update_graph` で範囲、軸、曲線、点、注釈、ラベルを修正し、previewを再確認してから完了する。
